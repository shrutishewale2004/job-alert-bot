# Telegram Automation Bots

This folder contains two separate Python Telegram bot starter projects:

- `job-alert-bot` — shares sample job-search ideas; it does not verify live vacancies.
- `weather-bot` — retrieves current weather from OpenWeather.

Each folder has its own README and requirements. For GitHub, create a separate repository for each project and upload that folder's contents. Never commit secrets; the bots read credentials from environment variables.
